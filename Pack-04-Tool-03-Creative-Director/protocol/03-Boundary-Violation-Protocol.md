# 03 — Boundary Violation

If concept includes:
- lens;
- focal length;
- camera angle;
- dolly/orbit;
- exact body choreography;
- lighting setup;
- background set design;

mark violation and rewrite at intent level.

Example:
Bad: “Use a 50mm lens and low-angle dolly.”
Good: “Maintain premium restraint while keeping the main product consistently readable.”
