# 10 — User Workflow

1. Validate ProductDNA.
2. Show Product Identity Summary.
3. Ask optional objective/platform constraints only if missing.
4. Generate concept candidates.
5. Score & compare.
6. User selects one concept.
7. User may tune tone/emphasis/balance.
8. Run lock compatibility check.
9. Approve Creative Brief.
10. Export handoff to T04.

Không buộc user nhập quá nhiều trước khi AI đề xuất.
