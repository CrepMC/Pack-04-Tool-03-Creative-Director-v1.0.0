# 05 — Product Emphasis Model

Mỗi brief phải chỉ rõ:
- primary product;
- secondary/companion;
- accessory preservation;
- identity-critical areas;
- what should receive viewer attention;
- what should remain visible but not dominate.

Ví dụ áo chính + quần phụ:
- Hero: upper garment silhouette, neckline, pattern.
- Support: beige-cream wide-leg pants.
- Preserve: straw hat if confirmed.
- Avoid: accessories overpowering shirt.

Không mô tả camera framing ở đây.
